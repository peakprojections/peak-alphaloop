Peak Alphaloop

A small, free video tool from Peak Projections: remove black, white or green-screen backgrounds to real transparency, make seamless mirror loops, and do basic multi-clip edits.

Built together with Claude, Anthropic's AI model, which wrote the code with us.

Open source under the MIT License · Source & releases on GitHub. Video processing by FFmpeg.

Everything runs on your computer. The only network request is an optional check for new releases on GitHub.
